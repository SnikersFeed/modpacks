# Пример файла сборки
#
# Всё, что лежит в packs/<id>/files/, попадает в архив pack.zip
# и раскладывается лаунчером в папку сборки с сохранением путей.
#
# Например:
#   files/mods/example-mod.jar  ->  <папка сборки>/mods/example-mod.jar
#   files/config/example.toml   ->  <папка сборки>/config/example.toml
#
# Замените этот файл и добавьте свои моды.
